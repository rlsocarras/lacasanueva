🏠 La Casa Nueva

Gestión de Stock Manual para Odoo 18

Versión 18.0.1.0.0 LGPL-3

📋 Descripción General

La Casa Nueva es un módulo para Odoo 18 que permite gestionar el stock de productos de forma manual, mostrando cantidades personalizadas en el sitio web sin afectar el stock real del inventario.

💡 Idea principal: El stock manual es informativo. No modifica el stock real (qty_available) ni las ubicaciones de inventario.

✨ Características Principales

📦

Stock Manual

Modifica el stock informativo sin afectar el stock real del inventario.

🌐

Badge personalizado en la web

Muestra un badge bonito con la cantidad disponible en el sitio web.

🔐

Permisos separados

Gestión interna y visualización en la web son permisos independientes.

🔄

Actualización por variante

El badge se actualiza automáticamente al cambiar de variante.

🔐 Sistema de Permisos

⚠️ IMPORTANTE: El módulo usa DOS permisos independientes que controlan cosas diferentes. Un usuario puede tener uno, otro, o ambos.

🔧 Permiso 1: Gestionar stock manual

Tipo: Grupo de seguridad

Ubicación: Ajustes → Usuarios → Derechos de acceso → La Casa Nueva

¿Qué permite?

  • ✅ Ver la sección "Stock Manual" en productos
  • ✅ Modificar manual_stock en variantes
  • ✅ Cambiar stock_display_mode del producto
  • ✅ Sincronizar con el sitio web

¿Dónde se usa?

Solo en el backend (Odoo interno)

🌐 Permiso 2: Es Asociado

Tipo: Campo booleano en el usuario

Ubicación: Ajustes → Usuarios → Pestaña "Preferencias"

¿Qué permite?

  • ✅ Ver el badge bonito en el sitio web
  • ✅ Ver el stock manual en lugar del stock real

¿Dónde se usa?

Solo en el frontend (sitio web)

📊 Combinaciones de permisos

Usuario Gestionar Stock Es Asociado Puede modificar stock Ve badge bonito en la web
Administrador ✅ Sí ✅ Sí ✅ Sí ✅ Sí
Usuario A ✅ Sí ✅ Sí ✅ Sí ✅ Sí
Usuario B ✅ Sí ❌ No ✅ Sí ❌ No (ve mensaje nativo)
Usuario C ❌ No ✅ Sí ❌ No ✅ Sí
Público ❌ No ❌ No ❌ No ❌ No
💡 Nota: Para que un usuario pueda modificar el stock manual necesita el grupo. Para que vea el badge bonito en la web necesita estar marcado como Asociado.

👥 Cómo asignar los permisos

1. Asignar el grupo "Gestionar stock manual"

  1. Ir a Ajustes → Usuarios → Usuarios
  2. Seleccionar el usuario
  3. Ir a la pestaña Derechos de acceso
  4. En la sección "La Casa Nueva", marcar "Gestionar stock manual"
  5. Guardar

2. Marcar al usuario como "Asociado"

  1. Ir a Ajustes → Usuarios → Usuarios
  2. Seleccionar el usuario
  3. Buscar el campo "Es Asociado" (pestaña Preferencias)
  4. Activar el checkbox
  5. Guardar
✅ Resultado: Si asignas ambos permisos al usuario, podrá modificar el stock manual desde el backend y ver el badge bonito en el sitio web.

📖 Uso del Módulo

Configurar un producto

  1. Ir a Inventario → Productos → Productos
  2. Abrir un producto
  3. Ir a la pestaña Inventario
  4. En la sección "Stock Manual La Casa Nueva"
  5. Seleccionar "Stock Manual" en "Mostrar en Sitio Web"

Productos SIN variantes

  1. Editar el campo "Stock Manual" directamente en el producto
  2. Guardar
  3. El sitio web mostrará el badge bonito con el stock manual

Productos CON variantes

  1. Ir a la pestaña Variantes del producto
  2. Hacer clic en una variante
  3. Editar el campo "Stock Manual"
  4. Guardar (el template cambia automáticamente a modo manual)
  5. El sitio web mostrará el stock manual de la variante seleccionada
⚠️ Importante: Al modificar el stock manual de una variante, el template del producto cambia automáticamente a modo manual. Esto hace que el sitio web muestre el stock manual en lugar del stock real.

🎨 Apariencia del Badge en la Web

El badge cambia de color y mensaje según la cantidad disponible:

Cantidad Mensaje Color
Más de 10 ✅ En stock — X unidades disponibles 🟢 Verde
1 a 10 🔥 ¡Últimas unidades! — solo X disponibles 🟡 Amarillo
0 ❌ Producto agotado — Consúltanos 🔴 Rojo
💡 Nota: El badge bonito solo se muestra a usuarios Asociados. Los demás usuarios ven el mensaje nativo de Odoo.

🛠️ Solución de Problemas

Problema Solución
No veo la sección "Stock Manual" Verificar que el usuario tenga el grupo "Gestionar stock manual"
No aparece el badge bonito en la web Verificar: 1) Usuario marcado como Asociado, 2) Producto en modo manual, 3) Stock manual modificado
El badge no se actualiza al cambiar de variante Recargar la página con Ctrl + F5 y limpiar caché del sitio web
Sigue apareciendo el mensaje amarillo de Odoo Limpiar caché del sitio web (Ajustes → Técnico → Website → Limpiar caché)
El stock manual no se guarda Verificar que el usuario tenga el grupo "Gestionar stock manual"
