Módulo de Gestión de Stock Manual para Odoo 18

Versión 18.0.1.0.0 LGPL-3 Producción

📋 Descripción General

La Casa Nueva es un módulo completo para Odoo 18 que permite la gestión eficiente del stock de productos de manera manual, sin necesidad de realizar entradas de almacén complejas. Diseñado específicamente para empresas que necesitan un control rápido y directo sobre su inventario.

💡 ¿Para quién es este módulo?
Empresas que necesitan actualizar rápidamente el stock de sus productos sin procesos administrativos complejos, manteniendo el control y la trazabilidad.

✨ Características Principales

📦

Stock Manual

Modifica el stock directamente desde la ficha del producto sin crear entradas de almacén.

🌐

Sincronización Web

El stock modificado se refleja automáticamente en la plantilla del sitio web.

👥

Control de Acceso

Solo usuarios marcados como "Asociados" pueden modificar el stock manualmente.

📊

Trazabilidad

Registro completo de quién modificó el stock y cuándo se realizó el cambio.

⚡

Actualización Rápida

Un solo clic para actualizar todo el stock de un producto y sus variantes.

🔒

Seguridad

Validaciones de permisos y prevención de stock negativo.

🚀 Instalación

  1. Copiar la carpeta la_casa_nueva al directorio de addons de Odoo
  2. Reiniciar el servidor de Odoo
  3. Ir a Aplicaciones → Actualizar lista de aplicaciones
  4. Buscar "La Casa Nueva" en el listado
  5. Hacer clic en Instalar
✅ Instalación Completa
Una vez instalado, el módulo estará listo para configurar y usar.

⚙️ Configuración

1. Configurar Usuarios Asociados

  1. Ir a Ajustes → Usuarios
  2. Seleccionar el usuario que será asociado
  3. Ir a la pestaña Derechos de acceso
  4. Marcar el checkbox "Es Asociado"
  5. Guardar los cambios

2. Configurar Productos

  1. Ir a Inventario → Productos
  2. Seleccionar un producto
  3. Ir a la pestaña Inventario
  4. Encontrar la sección "Stock Manual La Casa Nueva"

📖 Uso del Módulo

Actualización de Stock Manual

  1. Acceder a la ficha del producto como usuario asociado
  2. Ir a la pestaña Inventario
  3. Ingresar el nuevo stock en el campo "Stock Manual"
  4. Hacer clic en "Actualizar Stock Manual"
  5. Confirmar la actualización

Sincronización con Sitio Web

  1. Después de actualizar el stock
  2. Hacer clic en "Sincronizar con Sitio Web"
  3. El stock se actualizará automáticamente en la web
⚠️ Importante:
Solo los usuarios marcados como "Asociados" o administradores del sistema pueden realizar estas operaciones.

🔬 Funcionalidades Técnicas

  • Campos Relacionados: El stock manual se sincroniza entre plantilla y variantes
  • Tracking: Registro automático de cambios con usuario y fecha
  • Validaciones: Prevención de stock negativo y permisos de usuario
  • Wizard de Stock: Uso del wizard nativo de Odoo para cambios de stock
  • Notificaciones: Mensajes de éxito/error para mejor UX
  • Integración Web: Actualización automática de disponibilidad en eCommerce

🛠️ Solución de Problemas

Problema Solución
No veo el botón de actualizar stock Verificar que el usuario esté marcado como "Asociado"
Error al actualizar stock Verificar permisos y que el producto tenga ubicación de stock configurada
El stock no se refleja en la web Asegurarse de que el producto esté publicado en el sitio web
Stock negativo no permitido Esta es una característica de seguridad, no un error
